# مصادر نظام تصميم «بوينت · POINT»

مصادر بناء نظام التصميم لواجهات «بوينت» (تطبيق الموظفين) وعلامة العميل الفرعية «مصاف». الأولوية عند التعارض بترتيب القائمة.

| المسار | المحتوى |
|---|---|
| `tokens/tokens.css` | مصدر الحقيقة لكل القيم: متغيرات `--pt-*` بالوضعين الفاتح والداكن (`<html data-theme="light|dark|system">`). المكونات تستخدم الأدوار الدلالية فقط. |
| `tokens/tailwind.theme.css` | ربط الرموز بأدوات Tailwind v4 (`bg-surface`، `text-muted`، `bg-status-ready-bg`…). |
| `docs/03_Design_System.md` | المبادئ، سلم الخطوط، المسافات، المكونات وحالاتها وأسماؤها، الوصولية، الكتابة. |
| `docs/BRAND_GUIDELINES.md` | بنية العلامتين، قواعد الشعارات، الألوان، الخطوط، النبرة. |
| `preview/brand-preview-1..4.png` | معاينة بصرية حقيقية للهوية: الشعارات، الألوان، شارات الحالات، الخطوط، نماذج شاشات، محادثة «مصاف»، التذكرة الورقية. |
| `logos/point/` | شعار «بوينت» (أفقي RTL، عمودي، العلامة وحدها) بالفاتح والداكن. يُستخدم كما هو دون إعادة رسم. |
| `logos/masaf/` | شعار «مصاف» وصورة الحساب. لأسطح العميل فقط. |
| `fonts/` | IBM Plex Sans Arabic (400/500/600/700) للواجهة، وIBM Plex Mono (400/600) لأرقام التذاكر والرموز والعدادات. رخصة SIL OFL. |

قواعد ثابتة: عربي أولًا RTL، أرقام لاتينية 0–9، الحالة نص + لون + أيقونة، تباين WCAG 2.2 AA، أهداف لمس 44px على الأقل، وأزرار الأفعال التشغيلية للسائق 56px بعرض كامل.
