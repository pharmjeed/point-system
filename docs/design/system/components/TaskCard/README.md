# TaskCard

المهمة الحالية والتالية في D-04: رقم التذكرة، المركبة، `StatusChip`، المرحلة الحالية، وزر المرحلة التالية فقط (03 §3.4).

**المستهلك يوفّر:** `ticketNumber`، `status`، `vehicle`، `plate`، `stage`، `actionLabel` + `onAction` (Promise)، و`loading` / `error` / `disabled`. `next` يحوّلها إلى المهمة التالية: باهتة بشارة «تالية» وبلا أزرار حتى الترقية.

نصوص الأزرار من 02: «استلمت المفتاح»، «بدء الإحضار»، «وصلت — جاهزة»، «تأكيد التسليم».
