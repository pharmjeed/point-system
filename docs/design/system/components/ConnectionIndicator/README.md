# ConnectionIndicator

مؤشر الاتصال: نقطة ملونة + أيقونة + نص «متصل» / «الاتصال غير مؤكد» / «غير متصل» + وقت آخر مزامنة (03 §3.3).

**المستهلك يوفّر:** `state`، `lastSync` (نص الوقت، معزول LTR).

- النقطة بلون `pt-conn-*`؛ النص والأيقونة بلون `pt-success-text` / `pt-warning-text` / `pt-danger-text` لأن الكهرماني `pt-conn-uncertain` على الأبيض 2.12:1 فقط.
- الاتصال مؤشر مستقل لا يغيّر شيئًا في المهام بحد ذاته؛ عند `uncertain/offline` تعطَّل أزرار القبول والتسليم بنص «يتطلب اتصالًا» (03 §4.4).
