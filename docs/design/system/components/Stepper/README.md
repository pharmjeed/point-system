# Stepper

خطوات الإحضار الأربع: «المفتاح» ← «الإحضار» ← «جاهزة» ← «التسليم» (03 §3.6، D-10).

**المستهلك يوفّر:** `current` (0–3)، `steps` (`{label, time}`)، `detail` (الموقف والمنطقة للمكلف فقط)، `actionLabel` + `onAction`، `loading`، `error`.

الخطوة الحالية فقط تحمل زرًا؛ المكتملة بعلامة تحقق ووقت.
