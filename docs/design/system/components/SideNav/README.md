# SideNav

تنقل المشرف والإدارة من 1024px: «التشغيل» «السائقون» «المواقع والحفلات» «التقارير» + «الإدارة» لمن يملك الصلاحية (03 §3.2).

**المستهلك يوفّر:** `active`، `canAdmin`، `counts` (مثل `{ops: 7}`)، `onNavigate`، `logoTheme` (`light` · `dark`).

أعلاه الشعار الأفقي `lockup-rtl` (BRAND §2.2). العنصر النشط خلفيته `pt-primary-subtle` ونصه `pt-text` وأيقونته `pt-primary-text` (لا `pt-primary-text` على `pt-primary-subtle` داكنًا: 4.36:1). تحت 1024px تتحول الأقسام الأربعة إلى قائمة سفلية.
