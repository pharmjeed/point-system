# AlertItem

تنبيه للمشرف: النوع، الشدة، الوقت، وزرا «إقرار» / «حل» (03 §3.16).

**المستهلك يوفّر:** `severity` (`critical` · `warning` · `info`)، `title`، `type`، `time`، `acknowledged`، `loading` (`'ack'` · `'resolve'`)، `error`، `onAck`، `onResolve`.

الشدة نص + لون + أيقونة؛ الحرج بحد `pt-danger` سماكة 2.
