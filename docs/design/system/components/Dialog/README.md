# Dialog

تأكيد الإجراءات غير القابلة للتراجع، مع حقل سبب إلزامي حيث يلزم (03 §3.14، §4.5).

**المستهلك يوفّر:** `title`، `body`، `reasonRequired`، `destructive` (زر `danger`)، `confirmLabel`، `cancelLabel`، `loading`، `error`، `onConfirm`، `onCancel`؛ و`inline` للعرض داخل الصفحة.

يُستخدم للإلغاء، الإبطال، إعادة الإسناد، التسليم الاستثنائي، كشف الجوال، وتأكيد ربط واتساب.
