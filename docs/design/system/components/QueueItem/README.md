# QueueItem

طلب في طابور المشرف، الأقدم أولًا: الرقم، الحالة، المركبة، عدّاد الانتظار، شارات التصعيد، والمكلَّف إن وجد (03 §3.16).

**المستهلك يوفّر:** `ticketNumber`، `status`، `vehicle`، `plate`، `waiting`، `assignee`، `escalations` (`{level, label}`)، `critical`، `changed`.

التحديث الفوري لا يحرّك الصف الذي يتفاعل معه المستخدم؛ يُعلَّم «تغيّر» بدل القفز (03 §4.6).
