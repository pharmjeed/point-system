# Button

زر الفعل: إجراء رئيسي واحد بلون `pt-primary` في كل شاشة، وكل ما سواه ثانوي (03 §3.1).

**المستهلك يوفّر:** النص (فعل قصير من 02 §8)، `onClick` (يعيد Promise للأوامر التشغيلية)، و`variant` و`size`.

| الخاصية | القيم |
|---|---|
| `variant` | `primary` · `secondary` · `ghost` · `danger` · `success` · `reserve` (حجز كمهمة تالية) |
| `size` | `md` ‏48px · `lg` ‏56px بعرض كامل (أفعال السائق التشغيلية) |
| `loading` | مؤشر دوّار + «جارٍ…» + تعطيل؛ يُفعَّل تلقائيًا إن أعاد `onClick` وعدًا |
| `disabled` · `done` · `error` · `iconStart` · `fullWidth` | |

- **الحالات:** عادي، ضغط (`pt-primary-pressed`)، تركيز (`--pt-focus-ring`)، تعطيل (`pt-surface-2` + `pt-text-disabled`)، «جارٍ…»، نجاح لحظي (`done`، 600ms بعد رد الخادم)، خطأ (رسالة `pt-danger-text` تحت الزر ويبقى متاحًا).
- لا واجهة متفائلة: لا تُظهر «تم القبول» قبل رد الخادم. ولّد `Idempotency-Key` عند أول ضغطة وأعد استخدامه عند إعادة المحاولة.
- `danger` يكتب بـ`pt-text-inverse` (أبيض فاتحًا، كحلي داكنًا) لأن الأبيض على `red-400` في الداكن 2.8:1 فقط. `success` يستخدم زوج `pt-status-ready-*`.
- لا تستخدم الأزرق لأكثر من زر في الشاشة، ولا تضع أيقونة دون نص (استخدم `IconButton`).
