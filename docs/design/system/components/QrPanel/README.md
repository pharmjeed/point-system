# QrPanel

لوحة QR التي يديرها السائق نحو العميل (D-07): بيضاء دائمًا، شعار «مصاف» أعلاها، QR ≥240px، والخطوتان، وعد تنازلي لانتهاء الرمز (03 §3.13).

**المستهلك يوفّر:** `qrSrc` (QR بتصحيح أخطاء M وحواف بيضاء 4 وحدات)، `ttl` (من `link.qr_ttl_min`)، `expired`.

- **لا يظهر اسم «بوينت» ولا شعارها في هذه اللوحة.** هي سطح عميل بعلامة «مصاف».
- اللوحة تثبّت `data-theme="light"` ولو كان جهاز السائق داكنًا.
- عند وصول رسالة الربط يظهر للسائق `Dialog`: «وصلت رسالة الربط من رقم ينتهي بـ 123. هل هو جوال العميل الذي أمامك؟» بزرين «نعم، اربط التذكرة» / «لا، ليس هو».
- نص العد «ينتهي الرمز خلال…» مثال؛ النص المعتمد في 02 §8. الرمز في المعاينة مثال.
