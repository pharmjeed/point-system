# Checkbox

مربع اختيار 24px داخل هدف لمس 44px، والتسمية بجانبه (03 §3.10).

**المستهلك يوفّر:** `id`، `label`، `checked`، `hint`، `error`، `disabled`.

صندوق موافقة العميل في D-05 نصه: «وافق العميل على استلام رسائل «مصاف» على واتساب لهذه التذكرة» ومعه تلميح السؤال الشفهي — النصان من 02 حرفيًا (التلميح في المعاينة مثال).
