# IconButton

زر أيقونة وحدها بهدف لمس 44×44 و`aria-label` عربي إلزامي (03 §3.1).

**المستهلك يوفّر:** `icon` (اسم Lucide)، `label`، `onClick`؛ اختياريًا `variant` (`ghost` · `secondary` · `primary`)، `badge`، `loading`، `disabled`.

استخدمه للإغلاق والبحث والتحديث فقط؛ أي فعل تشغيلي يأخذ `Button` بنص.
