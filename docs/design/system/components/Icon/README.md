# Icon

أيقونات Lucide 0.468.0 بسماكة 2، مقاس 24 (20 داخل الأزرار المتوسطة، 16 في الشارات) — إضافة مقصودة: مكون واحد تستهلكه كل المكونات (03 §2.6).

**المستهلك يوفّر:** `name`، `size`، `label` (يجعلها `role="img"`؛ بدونها `aria-hidden`).

- الأيقونات الاتجاهية (`chevron-left/right`، `arrow-left/right`) تُعكس تلقائيًا تحت `dir="rtl"`؛ غيرها لا يُعكس.
- اللون `currentColor`: تأخذ لون النص المحيط.
- القائمة الكاملة في `Point.ICON_NAMES`. في Lucide الحالية: `check-circle-2` ← `circle-check`، `x-circle` ← `circle-x`، `alert-triangle` ← `triangle-alert`، `bar-chart-3` ← `chart-column`.
