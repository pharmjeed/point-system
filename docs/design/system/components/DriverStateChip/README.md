# DriverStateChip

شارة حالة السائق من `pt-driver-<state>-bg/-fg` (03 §3.3، Canon §5.6).

**المستهلك يوفّر:** `state`: `available` متاح · `intake_parking` يسجل/يصف · `retrieving` يحضر/يسلّم · `busy_with_next` مشغول ولديه مهمة تالية · `on_break` استراحة · `off_duty` خارج الوردية.

البنفسجي محجوز لمفهوم «المهمة التالية» وحده.
