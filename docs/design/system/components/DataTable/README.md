# DataTable

جدول المشرف: رأس ثابت، ترتيب، تصفية، ترقيم بالمؤشر؛ ويتحول إلى بطاقات تحت 1024px (03 §3.16).

**المستهلك يوفّر:** `columns` (`{key, label, sortable, render}`)، `rows` (`_changed` لتعليم «تغيّر»)، `sort`، `toolbar` (عادة `FilterChips`)، `layout` (`auto` بحاوية ≥1024px · `table` · `cards`)، `loading`، `loadingMore`، `error`، `hasPrev`، `hasNext`.

الطوابير بالأقدم أولًا، والسجلات بالأحدث أولًا.
