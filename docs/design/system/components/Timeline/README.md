# Timeline

سجل التذكرة (S-03): يدمج أحداث التذكرة والعهدة ورسائل واتساب بترتيب زمني، لكل عنصر أيقونة وفاعل ووقت (03 §3.16).

**المستهلك يوفّر:** `events` (`{kind: 'ticket'|'custody'|'whatsapp', text, actor, time, message?, failed?, icon?}`).

معاينة رسائل العميل تحمل علامة «مصاف» (صورة الحساب + الاسم) — أحد موضعين فقط تظهر فيهما «مصاف» داخل واجهة الموظفين.
