# StatusChip

شارة حالة التذكرة: نص + لون + أيقونة دائمًا، من `pt-status-<status>-bg/-fg` (03 §3.3، Canon §5.1).

**المستهلك يوفّر:** `status` بأحد المفاتيح: `received` مستلمة · `parking` جارٍ الصف · `parked` متوقفة · `requested` مطلوبة · `assigned` مُسندة · `assigned_waiting` محجوزة تالية · `retrieving` جارٍ الإحضار · `ready` جاهزة · `delivered` مُسلّمة · `reparking` جارٍ إعادة الصف · `voided` ملغاة. و`size="sm"` للقوائم.

- كل الأزواج ≥4.5:1 بالوضعين (أدناها `ready` فاتحًا 4.54:1).
- الأيقونة حلّت محل نقطة 8px في 03 §3.3 تنفيذًا لقاعدة «نص + لون + أيقونة» (انظر ملاحظات التعارض). الخريطة في `Point.TICKET_STATUS`.
- النص من القاموس فقط؛ لا تختصر ولا تجتهد.
