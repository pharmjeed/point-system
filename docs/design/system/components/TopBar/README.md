# TopBar

الشريط العلوي 56px: العلامة 28px + «بوينت» نصًا حيًا 18/700 أو اسم الموقع، وفي الطرف الآخر حالة السائق والاتصال (03 §3.2).

**المستهلك يوفّر:** `title`، `driverState`، `connection` (`online` · `uncertain` · `offline`)، `lastSync` (يظهر عند غير المتصل فقط).

لا تصغّر الشعار الأفقي الكامل هنا؛ العلامة وحدها + نص (BRAND §2.3). عند الضيق ينزل وقت المزامنة سطرًا ولا يُقص اسم الموقع.
