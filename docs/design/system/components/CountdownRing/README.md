# CountdownRing

حلقة العد التنازلي للعرض الفردي: قطر 56، سماكة 5، `pt-primary` ثم `pt-warning` تحت 10 ثوانٍ، والرقم في المنتصف (03 §3.5).

**المستهلك يوفّر:** `seconds` محسوبة من `expires_at - serverNow` (لا عداد محلي يبدأ من 30)، `total` (30).

خطية؛ مع `prefers-reduced-motion` يبقى الرقم ويُلغى الانتقال. يُعلن كل 10 ثوانٍ فقط.
