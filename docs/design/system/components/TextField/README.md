# TextField

حقل نص: ارتفاع 48، خط 16 (قاعدة iOS)، تسمية فوق الحقل دائمًا، خطأ تحته بأيقونة و`aria-describedby` (03 §3.10).

**المستهلك يوفّر:** `id`، `label`، `value`، `placeholder`، `hint`، `error`، `disabled`، `loading`، `dir` (`ltr` للرموز والأرقام)، `inputMode`.

حدود الحقل `pt-border-strong` (1.81:1 — انظر الملاحظات) وتصبح `pt-primary` مع حلقة التركيز، و`pt-danger` بسماكة 2 عند الخطأ.
