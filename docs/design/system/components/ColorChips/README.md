# ColorChips

لون المركبة: دوائر بنص تحتها للألوان الشائعة، والقيم مفاتيح إنجليزية تُترجم في الواجهة (03 §3.9).

**المستهلك يوفّر:** `value`، `onChange`، `error`، `disabled`. الخريطة في `Point.VEHICLE_COLORS`.

السواتش من القيم الأولية في الرموز (أبيض `pt-ink-0`، أسود `pt-ink-950`، فضي `pt-ink-300`، رمادي `pt-ink-500`، أحمر `pt-red-600`، أزرق `pt-blue-600`، بني `pt-amber-800`، بيج `pt-amber-100`، أخضر `pt-green-600`، ذهبي `pt-amber-500`)؛ هذا الاستثناء الوحيد لاستخدام القيم الأولية لأنها تمثل طلاء سيارة لا دورًا في الواجهة.
