# BottomNav

تنقل السائق السفلي: ثلاث وجهات فقط «الرئيسية» «المركبات» «حسابي»، أيقونة + نص، والنشطة `pt-primary-text` بوزن 700 (03 §3.2).

**المستهلك يوفّر:** `active`، `onNavigate`؛ و`items` بالصيغة `[key, label, icon, badge?]` لعدّاد اختياري.

الارتفاع `pt-bottomnav-h` + `safe-area-inset-bottom`. لا تضف وجهة رابعة للسائق.
