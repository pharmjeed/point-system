# PhotoTile

مربع صورة لزاوية المركبة (D-06): فارغ، جارٍ الرفع، مرفوع، فشل (03 §3.12).

**المستهلك يوفّر:** `angle` (أمام · خلف · يمين · يسار)، `state` (`empty` · `uploading` · `uploaded` · `failed`)، `progress`، `src`، `disabled`.

الضغط يفتح الكاميرا مباشرة (`capture="environment"`). اضغط الصورة في المتصفح (الضلع الأطول 1600px، JPEG 0.8) واحفظها في IndexedDB حتى يؤكد الخادم.
