# SpotGrid

شبكة اختيار المواقف أو خانات المفاتيح (D-08) من `venue.layout_read` (03 §3.15).

**المستهلك يوفّر:** `spots` (`{code, occupied}`)، `selected`، `allowNote` (حين يسمح `parking.mode`)، `error`، `disabled`.

المشغولة رمادية ومعطلة مع أيقونة مركبة؛ المختارة بحد `pt-primary` سميك (3px) وعلامة تحقق. الرموز بخط Mono داخل `bdi`.
