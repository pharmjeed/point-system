# Banner

شريط أعلى المحتوى، ثابت حتى يزول السبب، بأيقونة ولون دلالي وإجراء واحد (03 §3.14).

**المستهلك يوفّر:** `kind`: `offline` · `stale` · `audio` · `whatsapp` · `notifications` · `update`، و`message` / `actionLabel` / `onAction` / `loading`.

نص `audio` «الصوت متوقف — اضغط للتفعيل» من 03؛ بقية النصوص أمثلة حتى تُعتمد من 02 §8.
