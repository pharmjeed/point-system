# Point

شعار «بوينت» للموظفين فقط، كما ورد في المصادر؛ لا يُعاد رسمه ولا تُغيّر ألوانه ولا يصل إلى العميل.

- `point-mark.svg`: العلامة وحدها، أزرق `#015AFE` والدبوس مفرّغ (يأخذ لون الخلفية). TopBar للجوال بارتفاع 28px + «بوينت» نصًا حيًا 18/700. حد أدنى 24px.
- `point-mark-white.svg`: العلامة بالأبيض، على `pt-brand-blue` فقط (أيقونة التطبيق، شاشة البداية).
- `point-lockup-horizontal-rtl.svg` / `-on-dark.svg`: أفقي والعلامة يمينًا؛ SideNav ولوحة المشرف ≥1024px. حد أدنى 140px.
- `point-logo-stacked.svg` / `-on-dark.svg`: الكامل مع VALET & PARKING؛ شاشة الدخول والمستندات. حد أدنى 120px (تحته استخدم الأفقي أو العلامة).
- المساحة الآمنة: عرض ساق حرف P من كل جهة. الخلفيات المسموحة: الأبيض، `pt-brand-navy`، `pt-ink-50`، و`pt-brand-blue` بالنسخة البيضاء فقط.
