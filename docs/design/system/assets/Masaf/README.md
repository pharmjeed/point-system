- `masaf-wordmark.svg`: حروف كحلية `#031435` ودبوس `#015AFE`؛ على الفاتح. QrPanel والتذكرة الورقية. حد أدنى 64px عرضًا (16mm طباعةً).
- `masaf-wordmark-on-dark.svg`: حروف بيضاء ودبوس `#3D7BFF`؛ على الكحلي.
- `masaf-avatar.svg`: صورة حساب واتساب: خلفية كحلية مصمتة والكلمة بعرض 66% من القطر، تُعرض دائرية. بلا نصوص إضافية.
- المساحة الآمنة: ارتفاع رأس الدبوس من كل جهة.
