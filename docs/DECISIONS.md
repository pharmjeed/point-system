# سجل القرارات والأسئلة المفتوحة

معرّفات القرارات بالصيغة `DEC-##` (أعيدت تسميتها من `D-##` لتجنب الخلط مع معرّفات شاشات السائق `D-01…D-15`). القرار الجديد يأخذ الرقم التالي المتاح.

الإصدار 1.1 — 28 أكتوبر 2026. كل قرار هنا ملزم للتنفيذ حتى يُعدّل صراحةً في هذا الملف. القرارات المعلّمة «مالك» اتخذها صاحب المشروع؛ والمعلّمة «تصميم» اتُّخذت عند إعداد الحزمة ويمكن مراجعتها.
