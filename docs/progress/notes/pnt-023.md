## E2E fake backend

`e2e/support/fake/` is a small stateful fake of the API (test code only): it starts from the docs/17 §4 seed
(`packages/db/src/seed` ids, fixtures and dev credentials — files without runtime dependencies), keeps one world shared
by every attached page (one page = one session), and enforces the rules the UI relies on: session, CSRF header, the
canon §10 matrix from `@point/shared`, venue scope (404 for records out of scope, `SCOPE_VENUE_DENIED` for a chosen
venue), `Idempotency-Key` on required commands with replay and `IDEMPOTENCY_KEY_REUSED`, `expected_version`, and the
07/08 business errors with the 08 texts. Specs inject faults (`failNext`) or latency (`delayNext`) per route and read
every call. PNT-035 extends it for the driver path; see `pnt-035.md` for the real-API mode of PNT-036.

## Proposed decisions (numbering left to the lead)

**A — Who prepares the layout in acceptance 1.** PNT-023 AC-1 says a supervisor prepares RMS «(حفل، وردية، مواقف،
خانات)», but `venue.manage` (zones, spots, boards, slots, settings) is owner/admin only (canon §10, 09 §3) and 02 §2.2
makes S-09 view-only for supervisors. Kept the RBAC: the scenario has the administration create the layout and the
supervisor create and open the event and the shift; the supervisor then sees S-09 read-only. Fix: reword AC-1 to
«المشرف والإدارة» (or grant supervisors the layout, which would change canon §10).

**B — S-08 venue page route.** 02 §9.1 lists `/venues` (S-08) and `/venues/:venueId/setup` (S-09), while S-08 also
describes a venue page with «الحفلات» and «الورديات». Added `/venues/:venueId` for it; the tab is `?tab=shifts`, the
event groups «اليوم · القادمة · المغلقة» are a `SegmentedControl` (today = not finished with `event_date ≤ today` in
Riyadh, upcoming = later dates, closed = `closed`/`canceled`). Add the route to 02 §9.1.

**C — S-09 tabs as a section list.** The design system and 03 §3 have no tab component and six tabs do not fit a
`SegmentedControl` at 360 px, so S-09 shows the six tabs of 02 as `ListItem`s (with counts) that open the section
(`?section=parking|keys|pools|timers|handover|inspection`, `Header` back to the list). A design-system `Tabs` (Radix
Tabs is already allowed by 05 §5) can replace it later.

**D — Status chips for setup records.** Events, shifts, setup items and accounts have no `--pt-*` status tokens.
`StateChip` keeps the `StatusChip` anatomy (text + colour + icon) with the semantic feedback pairs, all in the contrast
check: event draft = info, open = success, closing = warning, closed = neutral (`surface-2` / `text-muted`), canceled =
danger; shift scheduled = info, open = success, closed = neutral; setup active = success, inactive = neutral; account
active = success, disabled = danger. Propose these as design-system variants.

**E — Copy that 02 does not define** (in `src/i18n/ar.ts`, listed in `test/copy.test.ts`; everything else is checked
word for word against 02): success toast «تم الحفظ.»; setup status «نشط» / «معطّل»; S-05 «الموقع», «كل المواقع»,
«لا يوجد سائقون مطابقون.», «بلا تعيين»; S-06 «الموقع», «السبب (اختياري)», «لا توجد مناوبة مفتوحة.», «لا توجد
تعيينات.», «التعيين الحالي», custody item types «مركبة / مفتاح / مهمة / مهمة تالية / مسودة استلام»; S-08 «تعديل
الموقع», «رمز الموقع», «اسم الموقع», «الاسم بالإنجليزية (اختياري)», «المدينة (اختياري)», «العنوان (اختياري)», «مجموعة
التوزيع», «اسم الوردية (اختياري)», «النهاية (اختياري)», «فتح الوردية», «{amount} لكل مركبة», «إلغاء الحفل», empty
states «لا توجد مواقع.» / «لا توجد حفلات في هذا القسم.» / «لا توجد ورديات.»; the close-shift confirmation is the S-08
sentence without the `shift_closed` identifier; S-09 «منطقة جديدة», «اسم المنطقة», «إضافة مواقف», «لوحة جديدة»,
«اسم اللوحة», «إضافة خانات», «مجموعة جديدة», «اسم المجموعة», «الافتراضية», «البادئة», «من/إلى», «تعطيل/تفعيل»,
counts «المناطق: n» etc., «القيمة خارج الحدود المسموحة (min–max).», units «ثانية / دقيقة / مللي ثانية», empty states.
Local "required field" checks reuse 02 §1.9 «راجع الحقول المظللة.».

**F — Setting labels and the S-09 tabs.** Labels are the «المعنى» column of canon §12 with the unit as a hint;
`dispatch.accept_grace_ms` is worded «بعد انتهاء العرض» instead of `expires_at`; `parking.mode` has no meaning text, so
«نمط الصف» with «مواقف مرقمة / وصف المكان / مختلط». `intake.draft_abandoned_alert_min` is in no 02 S-09 tab: not shown,
kept by the PUT (the whole object is sent). Proposed: list it under «المؤقتات» in 02 S-09. Local checks (02 S-09):
every value in the OpenAPI range, `single_offer_reminder_s ≤ single_offer_ttl_s − 5` (DEC-65), and the pricing
default pair (included ⇒ 0, per_vehicle ⇒ > 0).

**G — Occupied spot/slot on disable.** The 08 text of `PARKING_SPOT_OCCUPIED` / `KEY_SLOT_OCCUPIED` advises choosing
another spot (D-08 wording). On S-09 the 02 sentence «لا يمكن تعطيله الآن؛ مشغول بتذكرة مفتوحة.» is shown instead — an
exception to DEC-80. Fix: a context text in 08, or keep this exception documented.

**H — Adding a driver is one command.** 02 S-05 says `POST /v1/drivers` then `POST …/assignments` when a venue is
chosen; 07 accepts `initial_venue_id` in the create body. One command (one key, atomic) is used. Fix 02 S-05.

**I — S-05 basics.** `GET /v1/drivers` takes one `driver_state`, while «مشغول» is three states: the filter chips and the
search run over the venue's list (cursor pages read to the end). A venue `Select` stands in for the TopBar switch
«قاعة ريماس ▾» until the staff TopBar gets its venue picker (S-02, PNT-074). The large-screen table and the device
column (audio, notifications — not in `DriverListItem`) come with the live S-05 (PNT-084).

**J — Event and shift times.** Forms take local Riyadh date and time (UTC+03:00, no DST); an end at or before the start
is the next day; displays use `Asia/Riyadh`. New events start from the venue's `pricing.*` defaults (canon §12 «الافتراضي
للحفلات الجديدة»); an edit sends only the changed fields (pricing is locked after the first ticket, 07 §2.5).

**K — Spot labels of a range.** The UI sends `range {prefix, from, to}`; 07 does not say how labels are formed. 02's
example «A-01 إلى A-40» implies zero padding: propose 07 to state it (e.g. width of `to`, at least 2 when there is a
prefix; none without a prefix, as slots «1 إلى 120»). The e2e fake does that.

**L — Reset secret.** 03 §4.5 does not list it among the actions needing a confirmation, so it runs on the press and
shows the temporary PIN once (S-06 text); it revokes the driver's sessions, so consider adding it to 03 §4.5.
